# LabGuide v1.0

LabGuide 是一个面向 iPad 横屏使用的微孔板加样引导 PWA 原型。

## v1.0 已实现

- 96 / 384 孔板切换
- 单孔点击、拖动矩形选择、整行/整列快捷选择
- 单孔 / N孔 / 整行 / 整列加样单位
- 横向（先行后列）/ 纵向（先列后行）遍历
- 手动 / 自动推进，自动模式支持 1–60 s 间隔
- 未选择 / 待加样 / 当前 / 已完成 / 特殊状态颜色自定义
- 运行界面：返回 / 回退 / 下一个，当前孔高亮和进度显示
- 96/384 孔板四角板位校准，使用双线性插值映射所有孔位
- 每一步自动保存，支持恢复未完成实验
- PWA manifest + Service Worker，可部署后添加到 iPad 主屏幕并离线使用

## Mac 本地预览

在终端进入本项目目录：

```bash
cd LabGuide_v1.0
python3 -m http.server 8080
```

然后在 Mac 浏览器打开：

```text
http://localhost:8080
```

同一局域网中的 iPad 可以通过 Mac 的局域网 IP 访问，例如：

```text
http://192.168.x.x:8080
```

> 普通网页功能可用于局域网测试；iPad 上完整的 PWA 安装和离线缓存建议部署到 HTTPS 地址。

## 免费上线

本项目是纯静态网页，不需要 R / Python 服务器，也不需要数据库。可直接部署到以下免费静态托管平台：

- Cloudflare Pages
- GitHub Pages
- Vercel

部署后使用 HTTPS 地址在 iPad Safari 打开，再通过“分享 → 添加到主屏幕”安装。

## 当前版本定位

v1.0 先验证核心实验体验：

`选择区域 → 设置移动规则 → 开始 → 跟随高亮孔操作 → 回退/推进 → 自动保存`

后续版本再加入 BCA / ATP / CCK-8 / ELISA 等 SOP 模板、样本名和体积提示。
